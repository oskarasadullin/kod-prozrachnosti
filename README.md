# Код прозрачности — демо

Статичная копия рабочего места специалиста «Риски в кадастре» для просмотра:
https://oskarasadullin.github.io/kod-prozrachnosti/

Только просмотр: загрузка, анализ, проверка и фильтры работают в полной версии.
Реальные люди в данных показаны инициалами, ИНН скрыты. Исходный код —
https://github.com/EthanNewell/Zeus_Analytics

Сборка: `python manage.py export_demo <папка> --prefix /kod-prozrachnosti/` на копии базы.
